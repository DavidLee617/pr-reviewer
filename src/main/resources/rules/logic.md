逻辑正确性问题：代码能编译、能运行，但在某些输入或状态下结果是错的。

- 边界条件（off-by-one）：比较运算符用错（< 与 <=、> 与 >=）、循环边界、下标 / 偏移量计算差一
- 包装类型（Integer、Long 等）用 == 或 != 比较，比较的是引用而非数值
- 自动拆箱：包装类型可能为 null 时直接参与运算或赋给基本类型，会抛 NullPointerException
- Optional 直接调用 get() 而未判断；可能为 null 的返回值未检查就使用
- 状态流转：修改资源状态前未校验当前状态是否允许该操作，或改动后的条件放过了不该放过的状态
- 事务：修改数据的多步操作缺少 @Transactional；同一类内部调用（this.xxx()）导致 @Transactional 等代理注解不生效；部分失败时数据不一致
- 金额使用 double / float 计算，或 BigDecimal 运算后未设置精度和舍入方式
- 并发：先查后改的共享数据更新没有加锁或原子更新，存在竞态
- 条件、返回值或参数与方法名、注释、接口文档描述的行为不一致
